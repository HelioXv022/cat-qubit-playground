Cat Qubit Playground

Quantum computers are fragile: errors are their worst enemy. The cat qubit’s trick is to store information in two “valleys”, so that one of the two kinds of error almost never happens. Forget the formulas for now. Play with a few small experiments and you will see how it works.

How to read the pictures below

The light in a microwave cavity can be drawn as a point on a plane. The farther the point is from the centre, the more photons are in the cavity; the angle of the point around the centre is the phase of the oscillation. Physicists call this picture phase space.

Experiment 1One valley, or two

Light leaks out of the cavity, and we can also pump light in. What matters is how many photons are exchanged at a time. The arrows on the map show the direction of the “flow”; the closer the contour lines, the steeper the slope.

What you saw

Exchanging one photon at a time gives a single stable point. Wherever a point starts, it ends up in the same place, and the original information is washed out.

Exchanging photons in pairs gives two stable points: +α on the right and −α on the left. Call one 0 and the other 1, and you have exactly one bit. This engineered process is called two-photon dissipation, and it keeps pulling the state back to the bottom of a valley.

What this picture cannot show

Each point is one possible state of the whole cavity, not a photon. The points are classical: each one ends up either left or right, like a coin. A quantum state can sit in both valleys at once (Experiment 3), and this map cannot draw that. For example, start from an empty cavity, right at the centre. On the map the outcome looks like a coin toss. In reality the empty cavity has an even number of photons (zero), exchanging photons in pairs never changes that, and the state ends up as the even cat: a superposition of both valleys, every time. This is how cat states are prepared in the lab. Noise does the opposite: losing single photons at random turns that superposition into a plain coin toss.

Experiment 2Kick it and see if it flips

What you saw

The farther apart the valleys, the harder it is to hop across, and it gets harder exponentially. Ideally the bit-flip rate is proportional to e−2α²: each extra photon in the cavity cuts the rate by about a factor of seven.

This is not just theory. In experiments, cat qubits have gone more than ten seconds between bit flips, while ordinary superconducting qubits typically last less than a millisecond.

What the ball model leaves out

A ball stands only for the “centre position” of the state, and the noise is simplified to a random push. It shows qualitatively that farther valleys are harder to cross, but the numbers should not be taken literally: in the ball model the flip rate falls even faster than the true law. The correct law e−2α² comes from the overlap of two quantum states; Section 5 of the notes has the derivation.

Experiment 3Lose a photon

The ball picture can only show which valley the state is in. A qubit can also be in both valleys at once. This is called a superposition, and it is what “Schrödinger’s cat” refers to. What you saw

Lose one photon and the photon number goes from even to odd, and the fringes flip sign: the even cat has become the odd cat. This is the other kind of error, called a phase flip. A state that sits in a single valley shows no change. As with ordinary qubits, phase flips only hurt superpositions.

Removing photons in pairs does not change the parity, so the two-photon process that “locks” the cat causes no trouble of its own. But the cavity always leaks photons by itself, and the more photons there are, the faster it leaks: the phase-flip rate is proportional to α².

Idealised estimate: per error-correction cycle, the bit-flip probability is taken to be e−2α² and the phase-flip probability 10⁻³ × α². In real devices the bit-flip suppression is slower, and that is exactly what experiments are working on.

So what is good about cat qubits

This is a very good deal: a few more phase flips in exchange for almost no bit flips. Only one of the two kinds of error is left to correct, so the simplest repetition code is enough, and it needs far less hardware than protecting against both.

Experiment 5Put a code on top

A single cat qubit still suffers phase flips. The fix is a repetition code: line up d cat qubits and keep checking whether neighbours agree. A longer line corrects more phase flips. But every extra qubit is one more place where a rare bit flip can sneak in, and the repetition code cannot correct those. The curves below come from circuit-level simulations.

What you saw

Phase flips fall quickly as the code gets longer, while bit flips creep up, so the total has a lowest point: the best code size. A bigger cat has far fewer bit flips, so a longer code pays off. Going from 5 to 10 photons, the best size grows from 5 to 19 cat qubits and the logical error per round drops from about 6 × 10⁻⁴ to about 10⁻⁷. With a small cat (4 photons or fewer in this model) bit flips are so frequent that a longer code only makes things worse.

What if a code protects against both errors?

A surface code corrects both kinds of error with a two-dimensional grid of qubits. Its standard form (CSS) treats bit flips and phase flips alike. A variant called the XZZX code uses the same grid but relabels its checks so that it can exploit biased noise. Below, both codes have the same size and the same total error rate; only the bias of the noise changes.

What you saw

As the noise becomes more biased, the standard code stays at about 4 × 10⁻³, while the XZZX code keeps improving: at η = 1000 it makes about 11 times fewer errors with the very same qubits. The more biased the noise, the more it pays to tailor the code to it. The repetition code above is the extreme case: it gives up on correcting bit flips altogether.

Three things to take away

  • Exchanging photons in pairs creates two stable valleys: one serves as 0, the other as 1.
  • The farther apart the valleys, the exponentially rarer the bit flips.
  • The price is linearly more phase flips. But with only one kind of error left, correction is cheap.
